## 📌 What is this?

This repo tracks my progress through [Striver's SDE Sheet](https://takeuforward.org/interviews/strivers-sde-sheet-top-coding-interview-problems/) by [@takeUforward](https://www.youtube.com/@takeUforward) — a curated list of 191 problems that cover everything asked in FAANG-level interviews.

**Goal:** Finish all topics in 45 days, understanding each solution, not just memorizing it.
